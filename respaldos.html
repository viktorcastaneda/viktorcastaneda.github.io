Respaldo en servidor (100 % automático)

Incluido en respaldo-servidor/: un workflow de GitHub Actions que descarga toda la base (incluso los nodos que las reglas no exponen a la app, como casvel_inventory_v1) con la API REST de Firebase, en su formato nativo, y lo guarda en un repositorio privado cada día.
